Mobile Development

项目二：移动应用

这是一款使用 React Native 开发的跨平台任务管理应用，支持 iOS 和 Android。它通过统一的代码库实现了原生级的性能体验。

应用的核心功能包括任务创建、编辑、分类、设置提醒和进度跟踪。界面设计简洁直观，遵循原生平台的设计指南。

后端使用 Google Firebase 提供的 Firestore 实时数据库进行数据存储和同步，确保用户在不同设备间的数据一致性。

我们实施了离线优先的策略，允许用户在没有网络连接时也能操作任务，待网络恢复时自动同步数据，极大地提升了用户体验。

项目专注于高效的项目管理，提供日历视图和甘特图（模拟）功能，帮助用户可视化地规划和跟踪大型项目，提升工作效率。

技术栈详情

  • 框架: React Native
  • 后端: Google Firebase
  • 数据库: Firestore
  • 状态管理: Redux
  • 推送通知: Firebase Cloud Messaging

项目挑战与解决方案

挑战: 跨平台 UI 一致性和性能优化。

解决方案: 使用 NativeBase 组件库，并优化渲染循环以减少不必要的重绘。

成果与反思

应用下载量超过 5000，用户反馈平均分 4.5/5。这项目强化了我对移动开发的理解。
