Web Development

项目四：个人博客

这是一个从零开始构建的个人博客平台，旨在提供一个快速、安全且易于维护的内容发布环境。

后端使用原生 PHP 结合 MVC 设计模式进行开发，保证了代码的整洁和可维护性。数据存储则依赖于稳定的 MySQL 数据库。

我们实现了完整的内容管理系统 (CMS)，包括文章发布、编辑、标签分类、评论审核以及用户权限管理等功能。

为了提升加载速度和 SEO 表现，我们集成了缓存机制，并确保所有页面都遵循 W3C 标准和移动优先的原则。

博客支持用户注册和登录功能，并使用了安全的密码散列算法和 CSRF 保护，以防止常见的 Web 攻击，保障平台安全。

技术栈详情

  • 后端: 原生 PHP (MVC)
  • 数据库: MySQL
  • 前端: Bootstrap
  • 缓存: Memcached
  • 安全: CSRF 保护

项目挑战与解决方案

挑战: 防止 SQL 注入和 XSS 攻击。

解决方案: 使用 PDO 预处理语句和输入过滤。

成果与反思

博客每月访问量 10k+，SEO 排名提升。这强化了我的后端安全知识。
